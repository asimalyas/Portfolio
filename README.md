## 🎯 Key Features

### 🌟 Public Portfolio
- **⚡ Blazing Fast** — Vite build with code splitting and lazy loading
- **🌙 Dark / Light Theme** — Persistent theme toggle with smooth transition
- **📱 Fully Responsive** — Mobile-first design, works on every screen size
- **✨ Particle Background** — Dynamic animated particle canvas on the hero
- **🎠 Smooth Animations** — Scroll-triggered animations and micro-interactions
- **🔒 Graceful Fallback** — Works fully offline with local portfolio data if Supabase is not configured

### 🔐 Admin Dashboard
- **🛡️ Secure Auth** — Supabase email/password auth restricted to the owner email
- **📊 Analytics Dashboard** — Live charts: item counts, public/hidden status, section distribution
- **📝 Full CRUD** — Create, Read, Update, Delete for every portfolio section
- **🖼️ Image Upload** — File uploads to Supabase Storage with live previews
- **🤖 AI Autofill** — Upload a certificate/document → Gemini fills in the details automatically
- **👁️ Publish Control** — Toggle items public/hidden without deleting them
- **🔄 Sort Order** — Drag-free sort order control for every section

### 🤖 AI Recruiter Assistant
- **💬 Context-Aware** — Answers questions using only verified portfolio data
- **🚫 Hallucination Guard** — Never fabricates information not in the portfolio
- **🔑 Server-Side Key** — Gemini API key never exposed to the browser
- **⚡ Streaming Ready** — Serverless Vercel API endpoint for instant responses

## 🤖 AI Features

### 💬 Recruiter Assistant (`/api/chat`)

```
Visitor: "What technologies does Asim know?"
   │
   ▼
Vercel Serverless Function
   │
   ├── Loads Asim's full portfolio data as context
   ├── Sends to Gemini API with strict system prompt
   │   └── "Only answer from the provided data.
   │         Never fabricate information."
   └── Returns Gemini's response to the browser
```

### 🤖 Admin AI Document Autofill (`/api/extract-admin-item`)

```
Admin uploads a certificate PDF / image
   │
   ▼
POST /api/extract-admin-item
   │
   ├── Validates Supabase admin Bearer token
   ├── Downloads file from Supabase Storage URL
   ├── Sends file + field schema to Gemini
   ├── Gemini extracts: Title, Issuer, Date,
   │   Description, Credential URL, Categories
   │
   └── Returns extracted fields to admin form
       (only fills BLANK fields — never overwrites)
```

**Supported sections for AI autofill:**

| Section | Fields AI can extract |
|:---|:---|
| **📜 Certificates** | Title, issuer, date label, description, credential URL, categories |
| **🏆 Achievements** | Title, description, date, categories |
| **🏢 Experience** | Role title, company, type, location, period, description, responsibilities, technologies, company URL |

**Safety guarantees:**
- ✅ Requires valid admin auth token — rejects all unauthenticated requests
- ✅ Gemini API key is server-only, never in the browser bundle
- ✅ File size guard: max **8 MB** per upload
- ✅ AI never overwrites `image_url`, `sort_order`, or `active` fields
- ✅ AI fills only **blank/untouched** form fields
- ✅ Upload always stays available for manual editing if extraction fails

```bash

git clone https://github.com/asimalyas/Portfolio.git

# 3. Copy environment variables

npm run dev
```

### `vercel.json` Configuration

```json
{
  "framework": "vite",
  "devCommand": "vite --host 127.0.0.1 --port $PORT",
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "rewrites": [
    { "source": "/admin", "destination": "/index.html" },
    { "source": "/admin/(.*)", "destination": "/index.html" }
  ]
}
```

> **Why the rewrites?** React Router handles `/admin` and `/admin/*` on the client side. Without these rewrites, Vercel would return `404` on direct URL visits or page refreshes. The rewrites are scoped only to admin routes so `/api/chat` and `/api/extract-admin-item` continue to resolve as real serverless functions.

## 🔧 Troubleshooting

| Problem | Cause | Fix |
|:---|:---|:---|
| **Blank screen after login** | Auth state race condition | Hard refresh (Ctrl+Shift+R) — fixed in latest build |
| **Admin dashboard crashes** | `portfolioData.experience.roles` was undefined | Fixed with optional chaining — update to latest |
| **AI assistant not responding** | Missing `GEMINI_API_KEY` | Add key to `.env.local` and/or Vercel env vars |
| **AI autofill does nothing** | Admin not signed in / key missing | Ensure admin is logged in, check `GEMINI_API_KEY` |
| **Login fails** | Wrong email or user not created | Create user `asimalyas4440@gmail.com` in Supabase Auth |
| **Images not showing publicly** | Storage bucket policies misconfigured | Re-run `schema.sql` to recreate storage policies |
| **Direct `/admin` refresh → 404** | Missing Vercel rewrites | Ensure `vercel.json` has admin rewrites, redeploy |
| **Vercel API routes fail** | Server env vars not set | Add vars in Vercel → Settings → Environment Variables, redeploy |
| **Build warnings (chunk size)** | Large JS bundle | Expected — does not affect functionality |
